## 🚀 Sobre o Projeto

O **FocusEngine** é uma API moderna de gerenciamento de tarefas desenvolvida com arquitetura limpa, alta performance e foco em boas práticas de engenharia de software. O sistema conta com validações estritas, tratamento global de erros, documentação interativa e esteira de CI/CD automatizada.

## 🛠️ Tecnologias e Ferramentas

* **NestJS** (Framework backend em TypeScript)
* **TypeORM** (Gerenciamento de banco de dados)
* **Swagger** (Documentação interativa de endpoints)
* **Jest** (Testes automatizados unitários e E2E)
* **GitHub Actions** (Pipeline de CI/CD)
